Letakkan 8 file logo format .webp di folder ini dengan nama:

- javascript.webp    (logo JavaScript)
- photoshop.webp     (logo Adobe Photoshop)
- aftereffects.webp  (logo Adobe After Effects)
- blender.webp       (logo Blender 3D)
- live2d.webp        (logo Live2D Cubism - VTuber)
- alightmotion.webp  (logo Alight Motion)
- word2010.webp      (logo Microsoft Word 2010)
- excel2010.webp     (logo Microsoft Excel 2010)

Ukuran disarankan 256x256 atau 512x512, format .webp.
Jika file belum ada, website akan menampilkan kotak kosong (placeholder 1x1).
Ganti file placeholder 42 bytes ini dengan file asli Anda.

Cara convert PNG/JPG ke WEBP:
- Online: https://convert.io/png-to-webp atau https://cloudconvert.com
- Offline: pakai XnConvert / IrfanView
- PowerShell: gunakan cwebp (jika terinstall)

Setelah mengganti, jalankan: npm run dev atau npm run build
